# RuneScape plugins

Plugins for the RuneScape plugin beta. Downloads and pictures: https://www.rabbet.lol/plugins/

## Install

1. Download this repo (Code > Download ZIP) and unzip it.
2. Copy the folder of the plugin you want (the one with `main.lua`) into `C:\ProgramData\Jagex\RuneScape-BETA\dev_plugins\`. It should look like `dev_plugins\name-highlight\main.lua`.
3. In game, open the console. It takes one command per Enter. Type `prf`, then `pon` and the folder name, like `pon name-highlight`.

Retro UI Kit (`RetroUI`) is for plugin makers. The other plugins don't need it.

## Plugins

- `potion-planner` Apothecary: Plan potion batches, combine ingredients and work out what you need to buy.
- `hey-listen` Hey, Listen!: 3D arrows to track any NPC in the game.
- `bank-filters` Bank Filters: Find items to sort out and mark your own collections with custom bank presets.
- `hunter-manager` Hunter Manager: Keep track of your traps with clear highlights and colours for their different states.
- `summoning-hud` Summoning HUD: Keep familiar information together in an on-screen display.
- `alert` Alert!: Set reminders on backpack slots and choose a colour for their flashing alerts.
- `pixel-art-bars` Pixel Art Bars: Adds a configurable, cute little Pixel art HP and Adrenaline bar below your character.
- `soundbox` Soundbox!: Browse RuneScape sounds, play them and save your favourites.
- `sound-muffler` Ambient Sound Muffler: Turns down or blocks the game's ambient sound, or silences single sounds.
- `chat-range` Chat Range: See a range overlay around your character, with adjustable display colours.
- `name-highlight` Name Highlight: Your name, and any nicknames you add, light up in chat when someone says them.
  It needs chat access too: `ppr name-highlight`, then `ppe name-highlight chatAccess`, then `prf`, then `prl name-highlight`.
- `xp-meter` XP Meter: XP per hour and the time to your next level, for the skills you trained most recently.
- `tile-info` Tile Info: Shows where you are, in the numbers plugin makers need.
- `hover-inspector` Hover Inspector: Shows what the game's menu knows about whatever is under your mouse.
- `var-watch` Var Watch: Inspect game variables and export observations while building RuneScape plugins.
- `RetroUI` Retro UI Kit: The pixel-art window kit our plugins use, for plugin makers.
